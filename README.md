Проект для института

Описание модулей
1. EurekaServer - основной сервер, запускает реестр микросервисов на порту 8764
Его надо открыть после включения через http://localhost:8761/, что бы удостовериться что все сервисы поднялись
имеет основной одноимённый класс, с параметрами для запуска

2. Api-gateway - запускает шлюз общения между клиентом и микросервисами на порту 8080
Имеет 2 класса
Apigateway - основной класс с параметрами для запуска
RouteConfig - Класс-Настройщик маршрутов
